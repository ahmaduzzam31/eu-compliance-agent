EU Compliance Agent: evaluation results

Two question-answering systems over the EU AI Act, GDPR and two Central Bank of Ireland guidance documents, tested on the same 30 questions. Both run fully on a laptop with free, local models.

Code and README on GitHub. Every number on this page is read from docs/data.json, which a script builds from the saved files in results/.
